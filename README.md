# Maxxis HK Key Tags

3D preview of three motel-style key tags (45 × 90 mm) for the Maxxis Hong Kong event, December 2026.

Live page: https://joeyu0758-sketch.github.io/maxxis-hk-keytag/

- `index.html` – view-only 3D carousel (Spin / Front / Back, arrow buttons to switch tags)
- `design.json` – the artwork on each tag (colour, front and back items)
- `icon.png`, `wordmark.png` – Maxxis icon and wordmark, recoloured to print black
